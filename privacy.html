Privacy policy

The short version: Mammoth collects nothing, because there is no server to send anything to.

What the extension collects

Nothing. Mammoth Blocker has no account system, no server and no analytics. It never sends your browsing, your settings or anything else off your device.

How blocking works

Mammoth gives your browser a list of known junk domains using the browser's own blocking engine (declarativeNetRequest). The browser does the blocking. Mammoth doesn't read your traffic.

What stays on your device

  • Your settings: category switches, paused sites and custom blocks.
  • Your block count, if you turn counting on.

All of it lives in your browser's local extension storage. Remove the extension and it's gone. You can also export it yourself from the Options page as a plain file you can read.

The scam check

The "Check this page for scam signs" button reads the text, title, address and login forms of the tab you're on — only when you click it, and only that one tab. The check runs inside your browser. In Chrome it may also use the browser's built-in on-device AI model, which runs on your computer. The page is never sent to Mammoth or to any server, and the result is not saved.

Browser permissions, in plain words

  • Block content (declarativeNetRequest): lets Mammoth hand its block lists to your browser.
  • Storage: saves your settings on your device.
  • Alarms: adds up the block count every few minutes, only if you turn counting on.
  • Active tab and scripting: let the popup show the current site and run the scam check when you click.
  • Read browsing activity (optional, off by default): lets Mammoth count its own blocks for a running total. You turn it on yourself in Options.

This website

This site has no analytics, no ad pixels and no cookies. It loads the Lato and Source Sans 3 typefaces from Google Fonts, so Google's servers see a standard request for the font files (like your IP address and browser type). The site is hosted on GitHub Pages, so GitHub's servers see the standard technical logs any web host sees; see GitHub's privacy statement. We never see those logs and add nothing on top.

The "Does Mammoth block this site?" checker runs inside this page. What you type is not sent anywhere.

Links that leave this site

Links to GitHub, Ko-fi and browser stores take you to those services, which have their own privacy policies.

Changes

If this policy ever changes, the new version will be posted here with a new date. The code is public, so anyone can check that the extension does what this page says.
